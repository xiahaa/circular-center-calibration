# v0.2.0 — Modular calibration framework

Released on 2026-08-27.

Version 0.2.0 turns the initial circular-center implementation into a modular,
configuration-driven framework for reproducing the paper experiments and
extending the 2D/3D calibration pipeline.

## Highlights

- Added pluggable registries and YAML configurations for 2D center, 3D center,
  and ambiguity-resolution methods. Experiments can select multiple methods of
  one type or set unused method types to `null`.
- Added the paper-aligned `Ellipse Center`, `Mass Center`, `Refined Center`,
  `CGA`, `CGA-RANSAC`, `PCL SACMODEL`, `Homography Validation`, and
  `Quasi-RANSAC` implementations.
- Added reproducible configurations and bilingual guides for synthetic 3D
  accuracy, angular-support stress, target tolerance, synthetic 2D accuracy,
  pose estimation, Quasi-RANSAC evaluation, 3D runtime, and qualitative
  real-world calibration experiments.
- Added the official AAMED repository as a pinned submodule and integrated it
  into the Orbbec–Livox and Insta360–Hesai real-world workflows.
- Added joint calibration across all accepted frames, deterministic random
  seeds, structured JSON results, and qualitative projection overlays.
- Added an all-in-one Conda/Python installation path, the optional C++ PCL
  baseline, calibration-target specifications, and a project teaser.

## Compatibility notes

- The Python package now uses the standard `src/` layout.
- `circular-center-run` and experiment YAML files replace the legacy standalone
  experiment scripts.
- Legacy examples, duplicate experiment code, and obsolete repository metadata
  were removed.
- AAMED remains governed by GPL-2.0 as a separately maintained submodule; the
  top-level project remains Apache-2.0.

## Validation

- Python test suite: 56 tests passed.
- Release versions are aligned across CMake, Python package metadata,
  `CITATION.cff`, and the runtime package version.
