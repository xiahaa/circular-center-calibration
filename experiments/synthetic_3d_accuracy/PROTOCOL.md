# 三维圆心精度实验协议

本目录是论文第一个实验的完整、自包含实现。运行时只会读取本目录、中央方法
配置 `configs/methods/` 和已构建的 PCL 动态库，不会读取其他外部项目或论文
源文件目录。

## 执行入口

- `experiment.py`：组织样本生成、方法调用、统计和输出。
- `generators.py`：实现四种蒙特卡洛分布和离群点数据生成。
- `reporting.py`：生成逐次 CSV、汇总统计、论文柱状图和 LaTeX 表格。
- `protocol.yaml`：保存几何、噪声、方法预算、论文方法映射和论文参考值。
- `profiles/paper.yaml`：论文规模，四场景各 1000 次，五档离群率各 100 次。
- `profiles/ci.yaml`：使用缩减规模验证完整调用链。

## 四场景蒙特卡洛实验

每个场景都重新以种子 42 初始化 MT19937。每次试验生成：

- 圆心 `c ~ U(-2, 2)^3`；
- 半径 `r ~ U(1, 5)`；
- 法向量由三维标准高斯向量归一化得到；
- 三维坐标加入标准差 `0.2 m` 的独立高斯噪声；
- 指标为估计圆心与真实圆心之间的欧氏距离。

四个场景为：

| Panel | 配置 | 采样方式 |
| --- | --- | --- |
| A | 100 个点、完整圆 | 角度在 `[0, 2pi)` 均匀随机采样 |
| B | 100 个点、70 度圆弧 | `t = u^2 * 70deg - 0.2 * 70deg` |
| C | 12 个点 | 三个随机角度簇，簇宽在 `pi/30` 至 `pi/9` 之间 |
| D | 20 个点、总跨度 200 度 | 随机正间隔归一化后关于零角度镜像 |

Figure 对比的方法是直接 `CGA` 和 `PCL SACMODEL`。PCL 使用
`SACMODEL_CIRCLE3D + SAC_RANSAC`、距离阈值 `0.1 m`、最多 1000 次迭代和
`0.99` 成功概率。论文正文把方法概括为 CGA-RANSAC，但产生该图的历史实验
实际调用直接 CGA；本实现保留实际实验行为。

## 离群点实验

每个基础圆包含 50 个完整圆周采样点，坐标噪声标准差为 `0.1 m`。原实验的
100 份基础点云没有公开，因此本实现固定种子并确定性生成统计等价的基础圆：
圆心范围为 `[0, 5] m`，半径范围为 `[2, 5] m`，圆平面使用随机轴角旋转。

离群点数量定义为 `ratio * inlier_count`，不是最终点云总数的比例。每个离群点
的三个坐标都是 `[10, 20]` 内的整数。历史实现曾将 `0.01` 赋给整型扰动变量，
实际扰动标准差因此为零；这里直接实现其有效行为。离群比例为
`10%, 20%, 30%, 40%, 50%`。

Table 对比：

- `PCL SACMODEL`：阈值 `0.1 m`，固定预算 1000 次；
- `CGA-RANSAC`：阈值 `0.2 m`，五点最小集，固定预算 1000 次，只按内点数
  选择模型，最后在内点上重拟合一次。

论文表格将 `CGA-RANSAC` 简写为 “CGA”。`protocol.yaml` 中的
`paper_outputs` 显式保存了这层映射，程序内部和原始 CSV 始终使用完整方法名。

## 数据来源

四场景实验保留了随机引擎类型、随机分布和采样协议，但 NumPy 与 C++ 标准库
对均匀分布、正态分布和无放回采样使用不同的位流转换。离群点实验的 100 份
基础点云未公开。`protocol.yaml` 保存论文表格值和历史四场景均值，完整 profile
生成 `paper_comparison.csv`，量化本次运行与论文参考值之间的差异。
